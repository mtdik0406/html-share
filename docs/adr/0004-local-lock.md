# 4. 同期のロックは手元のマシンで取る

- 日付：2026-11-21
- 状態：採用

## 状況

2 つの `sync` が同時に走ると、一方が S3 の状態を読んでから実行するまでの間に、もう一方が書き換える。

## 決定

- `.html-share/sync.lock` を mkdir で作ってロックにし、持ち主の PID を書く
- 持ち主が死んでいるロックは引き継ぐ。引き継ぎは別のロックで 1 つに絞る

## 理由

- 使う端末は 1 台。S3 や DynamoDB でロックすると、AWS 側の仕組みと権限が増える

## 結果

- 別のマシンとの同時実行は防げない。使う端末を増やすなら見直す
