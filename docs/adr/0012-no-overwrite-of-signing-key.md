# 12. keys:store は、SSM の秘密鍵を上書きしない

- 日付：2026-11-21
- 状態：採用

## 状況

[ADR 9](0009-sign-in-lambda-with-ssm-key.md) では、`keys:store` は `--overwrite` を付けたときだけ、すでにある値を上書きした。[ADR 10](0010-signing-key-generations.md) で鍵の世代ごとにパラメータを分けたので、作り直しは新しい名前に置けばよく、上書きが要る場面はない。

`keys:store` が確かめるのは、秘密鍵が手元の `.keys/public.pem` と対であることだけで、CloudFront に登録した公開鍵とは照らさない。世代を上げ忘れて上書きすると、使っている世代の鍵が CloudFront と対でない鍵になり、作る URL がすべて通らなくなる。手元の古い秘密鍵は消しているので、戻せない。

## 決定

- `keys:store` から `--overwrite` をなくし、すでにある値は常に上書きしない。ADR 9 の `--overwrite` は、この ADR で置き換える
- 置き直したいときは、`keys:delete` か AWS のコンソールで消してから置く

## 理由

- 上書きの手段がなければ、世代を上げ忘れても、使っている鍵は壊れない

## 結果

- 作り直しを途中でやめて、まだ deploy していない世代の鍵を置き直すときは、消してから置く手順が 1 つ増える
