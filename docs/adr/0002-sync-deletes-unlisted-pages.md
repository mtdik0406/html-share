# 2. `sync` は設定を正とし、設定に無いページを消す

- 日付：2026-11-21
- 状態：採用

## 状況

署名付き URL は個別に取り消せない。配った URL を止める手段は、S3 のオブジェクトを消すことだけ。

## 決定

- 公開の操作を `sync` 1 つにする。設定にあるページを置き、中身が変わったページを置き直し、設定に無いページを消す
- 置き直し（配った URL で見える中身が変わる）にフラグは要求しない
- 2 ページ以上、かつ公開中のページの 2 割以上を一度に消すときは止め、`--allow-mass-delete` を求める
- 設定のページが 0 のときは、フラグがあっても止める

## 理由

- 公開をやめることと設定から外すことを同じ操作にすると、消し忘れで URL が生き続けることがない
- 割合だけで止めると、公開が数ページのときに 1 ページ消すだけで止まる。最小の件数を合わせて使う
- 0 ページは、設定の読み違いで全部を消す場合がほとんどなので、意図があっても止める
- 名前を `publish` にしないのは、npm・pnpm の組み込みのコマンドと紛らわしいため

## 捨てた案

- 設定の変更をほかの端末から取り込んでいなければ消さない歯止め：使う端末が 1 台なので入れない
