# 6. Node は 26 だけを使う

- 日付：2026-11-21
- 状態：採用

## 状況

このツールを動かすのは 1 台の端末だけ。2026-11 の時点で、Node 26 は Active LTS（2029-04-30 まで）、24 は Maintenance LTS（セキュリティと重大なバグの修正だけ、2028-04-30 まで）、22 は 2027-04-30 で終わる。

## 決定

- 使う Node は 26 だけにする。版は `.nvmrc` にだけ書き、CI もそこから読む
- `engines` を `>=26` にし、`pnpm-workspace.yaml` の `engineStrict` で、合わない Node では `pnpm install` を止める
- `@types/node` も 26 に合わせる

## 理由

- 動かす人がいない版を CI で確かめても、守るものがない
- 型の定義を動かす版に合わせると、手元にない API を書いたときに型チェックで止まる

## 捨てた案

- 22・24・26 をすべて CI で確かめる：使う人がいない版のために CI の時間が増える
