# 5. 依存は公開から 14 日たった版だけを入れる

- 日付：2026-11-21
- 状態：採用

## 状況

乗っ取られて公開された版は、数日のうちに見つかり、取り下げられることが多い。

## 決定

- `pnpm-workspace.yaml` の `minimumReleaseAge` を 14 日にする。満たさなかった依存は、満たす版まで下げた
- 修正版を待てない脆弱性のときだけ、パッケージ名と版を指定して例外にする（手順は README）
- pnpm 本体は `packageManager` にハッシュを付けて固定する
- 脆弱性は Dependabot のアラートで知る。自動の PR は作らせない

## 捨てた案

- 例外をパッケージ名だけで書く：以後のすべての版が下限なしで入る
