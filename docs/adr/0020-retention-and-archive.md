# 20. ページに保持期限を書けるようにし、公開をやめたページは保管庫に 90 日残す

- 日付：2026-11-23
- 状態：採用
- 置き換えたもの：[ADR 2](0002-sync-deletes-unlisted-pages.md) の「設定に無いページを消す」の消し方（保管庫へ移してから消す）

## 状況

ページの公開をやめるには、設定から外して `sync` するしかない。外し忘れたページは、いつまでも公開されたままになる。署名付き URL の期限（最長 30 日）を過ぎても、新しい URL を発行すればまた見せられる。

公開をやめたページは S3 から消える。手元の元の HTML や素材を消したり書き換えたりしていると、公開していた中身はもう手に入らない。

S3 のライフサイクルは、オブジェクトを消すかストレージクラスを変えるだけで、別のキーへ移せない。期限は最終更新の日から数えるので、置き直すたびに数え直しになる。

使う人は 1 人なので、IP を条件にした社内限定の URL は作らない。

## 決定

- 設定の `pages[]` の各ページに、任意で `retainUntil`（`YYYY-MM-DD`）を書ける。その日の終わり（`sync` を実行する手元の時刻帯）まで公開する。書かなければ期限はない
- 日付として正しくない値（`2026-02-30` など）は、設定の誤りとして止める
- `sync` は、`retainUntil` を過ぎたページを置かない。S3 にあれば、設定に無いページと同じく公開をやめる
- 公開をやめるときは、`pages/<slug>/index.html` を `archive/<slug>/index.html` にサーバー側でコピーしてから消す。同じ slug の保管庫は上書きする
- 保管庫のオブジェクトは、ライフサイクルで 90 日後に消す
- 期限を過ぎて公開をやめたページも、[ADR 3](0003-block-reuse-of-retired-slugs.md) の取り下げた slug として記録する。期限を過ぎて設定に残っているページの slug は、再利用の確かめの対象にしない
- 消しすぎの歯止め（ADR 2）は、期限を過ぎたページも、公開をやめるページとして数える
- 期限の確かめは `sync` を実行したときだけ行う。定期的に動く Lambda は作らない

## 理由

- 期限を設定に日付で書けば、いつ公開が終わるかが設定を読むだけで分かり、手元にも S3 にも隠れた記録が要らない
- 公開した日から数える方式は、公開した時刻をどこかに残す必要がある。S3 の最終更新は置き直しで変わり、手元の記録はその端末にしかない
- 保管庫の接頭辞を `pages/` の外にすると、`sync` の一覧・管理画面の一覧・署名（どれも `pages/` だけを扱う）に何も足さずに、保管庫のページが公開されない。署名は URL ごとなので、`archive/` の URL への署名を作る経路がなければ、閲覧用の Distribution からは読めない
- コピーを先にすると、途中で失敗しても、保管庫に入らないまま消えたページは出ない
- 保管庫に入ったページの期限は、コピーで作り直された日から数えるので、ライフサイクルの数え方のままで、公開をやめた日から 90 日になる
- 期限を過ぎたページを置き直すと、その期限より前に配った URL がまた見えるようになる。設定から外したページと同じ扱いにすれば、同じ歯止めで防げる
- 使う端末は 1 台で、`sync` は公開するたびに実行する。定期の Lambda は、S3 の書き込みと削除の権限を持つ実行の主体が増える

## 捨てた案

- ライフサイクルで `pages/` を期限切れにする：置き直すたびに期限が延び、保管庫にも移せない。設定に残っていれば次の `sync` が置き直す
- オブジェクトのタグで期限を表す：ライフサイクルはタグで絞れるが、上の置き直しの問題は変わらない
- 保管庫を別のバケットにする：コピーの権限とバケットが 1 組増える。閲覧からは、接頭辞を分けるだけで読めない
- バケットポリシーで閲覧用の Distribution の読み取りを `pages/*` に絞る：署名のない要求はもともと CloudFront が拒むので、守れる範囲が広がらない。CDK が作るポリシーを置き換えることになる

## 結果

- `sync` を実行しなければ、期限を過ぎたページも公開されたままになる。配った URL の期限までは見られる
- 期限を過ぎたページを 30 日以内に同じ slug で戻すことはできない（ADR 3）。別の slug にする
- 保管庫から戻す操作は作らない。中身が要るときは、AWS の CLI などで `archive/` から取り出す
- 設定のページがすべて期限を過ぎると、公開するページが 0 になり、`sync` は止まる（ADR 2）。最後のページの公開をやめるには、`cdk destroy` を使う
