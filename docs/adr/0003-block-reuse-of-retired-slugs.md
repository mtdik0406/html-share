# 3. 取り下げた slug を 30 日使わせない

- 日付：2026-11-21
- 状態：採用

## 状況

ページを取り下げても、それより前に配った URL は期限まで有効のまま。署名付き URL の期限は最長 30 日。同じ slug に別のページを置くと、古い URL を受け取った人に新しいページが見える。

## 決定

- `sync` で消した slug と時刻を `.html-share/retired.json` に残す
- 消してから、URL の期限の上限と同じ日数がたつまで、その slug を使う設定は AWS に問い合わせる前に止める

## 結果

- 記録は手元にだけある。別のマシンで取り下げた slug は分からない
- 記録を消すと、この歯止めは効かなくなる
